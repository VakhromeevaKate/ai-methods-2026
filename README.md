# Курс "Методы ИИ"

### Структура репозитория
- hometasks - домашние задания
- homework_n - директория, куда нужно добавлять файл с ДЗ (n от 1 до какого-то числа, ожидаемо - до 4)
- practices - код с семинаров

### Информация по дедлайнам
Дедлайн на ДЗ - 2 недели от семинара, на котором она была задана, если не был оговорен другой дедлайн

### Критерий оценки за ДЗ:
• максимально за ДЗ выдается 100 баллов
• за критичную ошибку снимается 10 баллов, за мелкую - от 1 до 5
• после дедлайна за каждую неделю пропусков снимается 20 баллов (от 100 идеальных)
• есть способ добрать баллы с помощью дополнительных сложных заданий (будут выдаваться по мере прохождения курса), максимальная «стоимость» такой задачи — 50 баллов

### Как сдавать ДЗ
• нужно склонировать себе в GitHub этот репозиторий
• в своей версии репозитория выполнить задание
• файл с ДЗ нужно назвать как <фамилия-и-о>.ipynb и положить его в директорию с нужным номером ДЗ
• закоммитить изменения и запушить их в свой репозиторий на GitHub
• выставить Pull Request в этот репозиторий в GitHub (там есть для этого кнопка)
